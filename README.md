# Industrial Engineering, Data & Decision Systems

A growing collection of projects combining industrial engineering, operations research, simulation, optimization, data analytics, machine learning, quality engineering, and software-based decision support. Each project is documented in its own reproducible repository.

## Projects

- [Anodizing Line Simulation and Optimization](https://github.com/ArmutS/anodizing-line-simulation) — Discrete-event simulation of a multi-hoist anodizing line, simulation-driven load sequencing with Simulated Annealing, and explainable hoist dispatching. The work also produced a [research publication](https://www.ijfmr.com/research-paper.php?id=85464).
- [Anodizing Field Logger](https://github.com/ArmutS/anodizing-field-data-collector) — Android application for collecting hoist and station time-study observations used as simulation inputs.
- [Olist Delivery Risk](https://github.com/ArmutS/olist-delivery-risk-portfolio) — Point-in-time-safe machine learning workflow for predicting e-commerce delivery-delay risk.
- [Retail Analytics Decision Support](https://github.com/ArmutS/retail-analytics-decision-support) — Reproducible market-basket analysis with Apriori and daily-revenue forecasting with evaluated SARIMA models.
